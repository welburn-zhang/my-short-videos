## 核心结论

- 这套风格的主体是真实截图、录屏、表格和观点文字，不是 AI 科技装饰。
- 常规讲解使用左下圆形真人；观点和总结可切换成无人物的全屏大字幕。
- 黑色背景负责建立统一舞台，黄色和橙色负责标记重点，紫色只做少量人物边缘或氛围点缀。
- 不默认使用 3D 机器人、全息立方体、神经网络、空间网格和大量发光线。

## 使用方式

生成新分镜时，先根据语义选择最接近的一至两张参考图作为图片生成参考；不要把五张图的所有元素同时塞进一张画面。
