# 张半蛋人物形象参考

本目录保存张半蛋本人各角度形象照，用于后续短视频封面图生成时作为人物形象基底参考。

## 使用规则

- 生成短视频封面图前，默认先参考本目录的人物形象照，再结合 `素材库/短视频封面制作规则.md` 生成。
- 默认以本目录新增的真人照片为人物形象基准；AI 工具、Skill、Agent、工作流类封面优先参考 `03_思考姿态_黑色上衣_近景.jpg`。
- 正面口播类封面优先参考 `01_正面_白色上衣_麦克风_横版.jpg` 和 `02_正面_白色上衣_麦克风_近景.jpg`；思考、判断、复盘类封面可参考 `04_思考姿态_灰色卫衣_半身.jpg`。
- 封面人物应保持亚洲男性、黑色短发、清爽自然、真实创作者气质，脸型、发际线、眉眼和鼻梁不要做成泛化网红男。
- 人物表情可以有反应感，但不追求极度夸张；不要生成过度网红化、二次元化或与本人差异很大的形象。
- 生成图仍需遵守项目封面规则：高对比大字、清晰主题物件、搞笑/抽象/搞怪但不无厘头，真实任务和真实判断优先。

## 文件说明

- `01_正面_白色上衣_麦克风_横版.jpg`：横版正面口播参考，适合真实口播感封面。
- `02_正面_白色上衣_麦克风_近景.jpg`：近景正面口播参考，适合清爽真人封面。
- `03_思考姿态_黑色上衣_近景.jpg`：黑色上衣近景参考，适合 AI 工具、Skill、Agent、工作流类封面。
- `04_思考姿态_灰色卫衣_半身.jpg`：灰色卫衣半身参考，适合思考、判断、复盘类封面。
