# 每周工作流

> 默认创作时间为每天 20:00—22:30。产量服从质量和真实表达，不硬凑周更数量。

## 核心原则

1. 同类任务集中处理，减少写、拍、剪之间的切换。
2. 脚本、分镜、资产、剪辑按顺序推进，不跳过确认。
3. 数据用于检查表达，不直接决定选题方向。
4. 选题优先看表达欲、真实案例和长期价值。

## 建议节奏

| 阶段 | 主要任务 | 完成标准 |
| --- | --- | --- |
| 选题 | 从灵感和选题池中确认本周内容 | dbs 判断已确认 |
| 脚本 | 学习近期表达，生成并完成去 AI 味 | 五部分脚本已确认 |
| 封面 | 确认文案和主标题后生成两版封面 | `3:4`、`4:3` 均通过缩略图检查 |
| 分镜 | 逐项确认画面和资产来源 | 清单中没有“待确认” |
| 资产 | 准备真人口播、录屏、截图和待生图素材 | 所有路径回填且验收完成 |
| 剪辑 | 按已确认清单剪辑 | 画面、字幕、节奏和审核风险通过 |
| 发布 | 双平台发布并记录状态 | 平台后台可确认 |
| 复盘 | 周复盘或双周复盘 | 形成表达观察，不追单条波动 |

具体日期可以根据工作量移动，不为了遵守星期安排打乱内容质量。

## 单条内容流程

```text
1. 选题评估
2. dbs 核查并确认方向
3. 学习最近 3 份已确认或已发布脚本
4. 生成内部初稿并调用 humanizer
5. 输出五部分完整脚本
6. 确认封面文案和主标题
7. 用 Codex 内置 imagegen 原生生成 3:4、4:3 封面
8. 检查缩略图可读性，并询问是否压缩
9. 逐项确认分镜与资产
10. 制作并验收缺失资产
11. 正式剪辑
12. 发布、提取素材、更新选题状态
```

封面文字必须由生图模型原生生成，禁止用 PIL、Canvas、HTML、SVG、剪映、醒图、Canva 或固定模板后期排字。

## 批量处理建议

- **脚本**：集中做方向判断和脚本确认，但每条都要单独检查真实表达。
- **拍摄**：同一机位和灯光下连续拍摄，保留最自然的版本。
- **录屏与截图**：按分镜清单一次性准备，真实数据先脱敏。
- **生图**：只处理清单中已确认的“待生图”项目。
- **剪辑**：资产全部完成后再批量粗剪、字幕、节奏和音效。

## 发布与复盘

- 发布状态以创作者确认或平台后台为准，本地存在视频文件不等于已发布。
- 发布前检查标题、封面、标签和前 10—30 秒的就业焦虑词及外网工具风险词。
- 周日或每两周集中复盘一次：重点检查开头是否留住、表达是否听懂、评论是否有真实共鸣。
- 不因单条小样本数据修改定位、栏目或长期方向。

## 每周检查

- 本周真正想表达的内容是否讲清楚？
- 哪个开头最容易被听懂，哪个地方太绕？
- 分镜和资产是否在剪辑前完成确认？
- 发布状态、作品目录和选题池是否同步？
- 下周最想讲、真实案例最充分的题目是什么？
