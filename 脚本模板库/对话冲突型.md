# 脚本模板：对话冲突型

适用于面试、职场沟通、用户对话和“做错了 / 做对了”的场景还原。

## 内容结构

```text
直接进入冲突
→ 对话升级
→ 暂停拆解关键问题
→ 正确示范
→ 点题与迁移
```

| 预计发布日 |  |
| 预估时长 | 按实际对话和真实语速估算 |

### 二、封面 / 标题 / 标签

- 封面文案：
- 短视频主标题：
- 话题标签：

默认只写一个双平台通用版本。

### 三、开头候选

1. **真实任务 + 前后对比**：[同一场景里的错误版和正确版]
2. **痛点 / 尴尬场景**：[第一句直接暴露冲突]
3. **结果承诺 / 悬念**：[先说后果或反转结果]

正文使用推荐版本；对话型内容优先第一句直接进场。

### 四、脚本文案（拍摄版，剪映分批录制）

```text
[角色 A：第一句直接抛出冲突]

[角色 B：真实回应]

[冲突升级或暴露根本问题]

[张半蛋暂停场景，拆解哪里出了问题]

[正确版本：用具体对话重新演示]

[点题：这件事还能迁移到什么场景]

好了，记得点赞收藏+关注，后面我会分享更多适合小白观看的AI内容，我们下期再见，拜拜。
```

角色台词要像真实对话，不用概念解释代替冲突。
