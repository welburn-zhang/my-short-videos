# 脚本模板：深度价值型

适用于需要讲清一个问题、原因和解法的内容。时长由内容决定，不硬凑。

## 内容结构

```text
具体场景或反常识判断
→ 问题为什么发生
→ 一个核心解法
→ 真实案例、操作或结果对比
→ 可迁移原则
→ 最小行动
```

### 三、开头候选

1. **真实任务 + 前后对比**：[具体任务、原结果、新结果]
2. **痛点 / 尴尬场景**：[观众正在经历的具体场景]
3. **结果承诺 / 悬念**：[先给结果，再留下关键问题]

正文使用推荐版本。

### 四、脚本文案（拍摄版，剪映分批录制）

按自然语义段落写，不一句一行。

```text

[迁移：这套方法还能用到哪里]

[最小行动，可选]
```
