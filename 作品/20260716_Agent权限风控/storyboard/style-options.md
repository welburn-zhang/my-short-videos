# Agent 权限风控｜分镜视觉风格样稿

## 共同要求

- 比例：`16:9` 横版。
- 内容：用同一幅“沙箱工作区”概念检验视觉风格、信息层级、中文标签、圆形人物位和字幕安全区。
- 人物布局：`bottom-left-avatar-slot`，左下圆形窗口后期放入真人视频，样稿中不生成人物。
- 色彩：深黑蓝、午夜蓝、深靛蓝为主，使用冰蓝、青蓝和冷紫作为发光色，不使用暖色底图。
- 文字：画面内保留理解概念所需的简短中文标签，不堆叠长段落。

## A｜深色结构化信息界面

- 文件：`style-option-a-dark-ui.png`
- 特点：深靛蓝玻璃卡片、边界门禁清楚、信息结构最规整。
- 适合：规则说明、权限设置、步骤解释和电脑录屏底图。

## B｜深蓝全息实验室

- 文件：`style-option-b-holographic-lab.png`
- 特点：立体全息工作区、空间感和未来感最强，画面更有冲击力。
- 适合：Agent、沙箱、权限边界等技术概念。

## C｜神经网络电影科技感

- 文件：`style-option-c-neural-cinematic.png`
- 特点：电紫神经网络和钴蓝能量流，神秘感和叙事感最强。
- 适合：抽象概念、转场和总结判断。
