# ChatGPT 史诗级改版更新｜拍摄方向

## 拍摄定位

- **内容类型**：热点科普 + 功能地图 + 两组案例；作为一次独立的热点内容，不代表账号转向常态化的功能播报。
- **目标观众**：已经会用 ChatGPT 聊天、查资料或处理临时问题，但还不知道 Chat、Work、Codex 分别适合做什么的普通职场人和学习者。
- **建议时长**：7—8 分钟。
- **核心问题**：这次更新后，普通人打开 ChatGPT 的体验到底有什么不同？临时问答、完整任务和编程项目，分别该进哪个入口？
- **一句话方向**：从 2022 年大家熟悉的网页聊天框，到新的桌面端工作台，ChatGPT 的重点从“问一句、答一句”延伸到“把一件事交出去推进”；先用功能地图看清三个入口和新能力，再用两组案例看懂模板、可视化和 Sites 能拿来做什么。

## 核心判断

- 不把这次变化讲成“GPT 和 Codex 两个模型合并成一个 Agent”。准确表达是：Codex 的能力被纳入新的 ChatGPT 桌面端工作方式，产品入口完成整合。
- 用户真正的门槛不是先理解 Agent、终端或代码，也不是理解产品策略，而是先知道自己眼前的任务该进哪个入口。
- 开头类型确定为“热点判断 + 前后画面对比 + 教程承诺”：先让观众看到 2022 年网页聊天框与新桌面端的变化，再承诺讲清普通人最该用的功能和案例；不再用“从 Chat 时代到 Agent 时代”的概念解释起手。
- “近四年来最像换了一次产品的改版”是本条视频的创作者判断，不说成官方定性；用“可能是”“我认为”保留判断边界。
- 三个入口的用户体验与任务差别：
  - **Chat**：即时问答、查资料、改一段内容、临时想思路；可以理解为更强的搜索和对话入口，但不把它讲成只能搜索。
  - **Work**：把跨资料、跨步骤、需要交付物的非编程任务交给 AI 推进，适合工作、学习和生活中的完整小任务。
  - **Codex**：开发者优先的项目与编程环境，适合改代码、看 diff、跑终端、检查结果；不把它讲成普通人绝对不能使用的工具。
- 这条视频的主观点不是替 OpenAI 解释“为什么要拆”，而是让观众知道：这次更新后，自己能获得什么新体验、不同任务该进哪个入口，模板、可视化和 Sites 这些新能力又能拿来做什么。

## 三段视频结构

### 第一段：热点钩子与改版背景（约 25—30 秒）

前 17 秒先完成“热点是什么、为什么和我有关、这条能学到什么”，再进入产品解释。

- **0—3 秒｜前后对比**：左边放 2022 年大家熟悉的网页聊天框，右边放新的桌面端里 Chat、Work、Codex 同处一个界面；大字只传达“从聊天框到工作台”。
- **3—8 秒｜热点判断**：把“这次不只是换模型，可能是 ChatGPT 上线近四年来最大的一次产品改版”作为判断抛出，并保留“可能是 / 我认为”的个人判断边界。
- **8—17 秒｜结果承诺**：先用一句完整承诺锁住观众：**“今天这条，帮你看清 ChatGPT 这次改了什么、普通人最该用哪些功能，再用两个实际案例演示具体怎么用；看完你就知道新版桌面端里，Chat、Work、Codex 该怎么选。”** 画面同步打出三项短标签：`改了什么`、`重点功能`、`实际演示`。
- **17—30 秒｜压缩背景**：这时只说用户能感到的变化：以前多数人把它当问答或搜索入口；现在临时问题、完整任务和编程项目都有了更明确的入口，也能把跨资料、跨步骤的任务推进到交付物。不讨论 OpenAI 为什么要这么拆。
- 不从 Sol / Terra / Luna 等模型命名讲起，模型升级只作为后文解释能力变化的一句话背景。
- 这里的“网页聊天框 vs 桌面端”是历史使用方式与产品组织方式的对比，不说成“网页端不能干活、只有桌面端能用 Work”。

### 第二段：这次更新给普通人带来什么不同（约 2 分钟）

- 先纠正常见误解：这不是“模型合并”，而是产品入口和工作方式整合。
- 先用 15—20 秒讲 GPT‑5.6 本身，给后面的功能地图一个底座；只讲普通人能理解的差别，不念模型参数和性能榜单。

#### GPT‑5.6：模型定位，不做性能解读（约 15—20 秒）

- **三档模型，不是三种工作模式**：Sol 是能力最强的一档；Terra 是日常任务的平衡档；Luna 更偏速度与成本。用一句大白话解释：同一件事可以按“最强、够用、快一点”三种取舍来处理。
- **推理力度**：只用一句解释，它决定 AI 愿意花多少时间检查和修改；不展开 medium / high / max 的设置教学。
- **Ultra**：只说明它会让多个 Agent 并行处理复杂任务；不展开流程和性能对比。
- **官方对比图**：可作为过场截图，角落标注“OpenAI 公开对比数据”，不口播具体分数、不做竞品排名。

- 用三张同尺度截图讲清三个入口，不录完整操作：
  - **Chat**：临时问一句、改一段内容、快速拿答案。
  - **Work**：把资料和目标交出去，推进成一份可检查的成果。
  - **Codex**：进入项目改代码、看 diff、检查结果。
- 再用一张“新版功能地图”一笔带过本条重点的新能力：
  - **模板能力**：把认可过的周报、PPT 格式沉淀下来，以后反复复用。
  - **Visualize**：把表格或资料变成能看、能点的可交互页面。
  - **Sites**：把完成的小页面变成别人能直接打开使用的网页。
  - **插件**：安装可复用的工作流、连接工具和共享上下文，不再每次从零描述流程。
- 浏览器、电脑操作、定时任务等既有能力不在本条展开，也不放进功能清单，避免观众误以为它们都是这次新增。
- 功能地图后立刻转场：“这些名字看着多，下面不逐个念功能，直接拿两个任务跑一遍。”

### 第三段：普通人到底怎么用（约 5 分钟）

先给出判断法。三个入口只用截图配一句大白话讲清区别，不做完整录屏教学：

- 只需要一个答案、一个思路或一段临时内容，用 Chat。
- 需要从多份资料出发、持续推进、最后交一份成果，用 Work。
- 需要进入项目、修改代码、查看文件改动、跑终端和验收结果，用 Codex。

然后把本条重点的新能力收成两组简单案例。每组用“原始素材 → 结果成品”的前后截图展示，不演成完整长项目。

#### 案例 A：周报 / PPT 模板

- **Template Creator**：拿一份脱敏的旧周报、Word 或 PPT，说明它可以被沉淀成以后重复调用的个人模板；以后不是每次从空白文档开始。
- **系统模板（以实际界面显示为准）**：快速展示可直接成为新汇报、项目启动稿或表格版式起点的模板。
- **要让观众看懂的结果**：不是“AI 会做 PPT”，而是“我已经认可的一套格式，以后可以反复复用”。
- **演示素材建议**：一份脱敏的旧周报 / 汇报 PPT，或一页 Word 文档；准备“原始版式 → 模板 → 新内容复用后的成品”三张画面。

#### 案例 B：数据 / 可分享网页

- **Visualize**：拿一张很小的脱敏表格或 8—10 行示例数据，把信息变成可交互的图表、对比页面或小工具。
- **Sites**：把一个已完成的小页面变成可分享的网页，让别人不必打开源文件也能查看和使用。
- **要让观众看懂的结果**：不是“AI 会写网页代码”，而是“原本躺在表格或文档里的东西，可以变成别人点开就能看、能用的页面”。
- **演示素材建议**：一张项目进度、学习计划或周数据的简化表；准备“原始表格 → 可视化页面 → 可分享网页”三张画面，数字和名称全部脱敏。

## 画面与表达重点

- 前 5 秒必须先给“旧网页聊天框 → 新桌面端工作台”的真实对比画面；模板、可视化、Sites 和案例成品放在教程承诺之后，不抢热点钩子。
- 桌面端是三种入口最直观的集中展示，不把它讲成网页端功能的替代品。
- 模型段只占第二段前 15—20 秒：让观众知道“最强、够用、快一点”的取舍即可，再把重点还给功能地图和两组案例。
- 性能画面如使用 OpenAI 官方对比表，必须标注来源；不口播分数、不截取第三方总榜暗示“全球第一”。
- Chat、Work、Codex 各用一张同尺度截图配大字说明；截图里可利用“文档 / PDF / 表格 / 插件”的图标，强化 Work 更像办公入口的体感。
- Codex 截图保留 diff、终端或项目文件的代码感画面，但不录完整代码操作。
- 功能清单只保留模板、Visualize、Sites 和插件；浏览器、电脑操作、定时任务等既有能力不提。
- 不把 Work 说成“非程序员专属”，而是说它优先承接非编程任务；不把 Codex 讲成“只有程序员能用”。
- 2—3 个 Prompt 只作为帮助观众立即上手的收口，不追求“一句话完美完成”；优先给 Work 与 Codex 各一个，必要时补一个 Sites / 模板类示例。

## 事实与审核注意

- 不使用“GPT 和 Codex 模型合并”“ChatGPT 10 亿周活”“WorkBuddy 千万日活”等未经精确核实或容易引发争议的表述。
- “四年来最大改版”不作为官方事实口播；可以作为个人判断说“我认为 / 可能是近四年来最像换了一次产品的改版”。
- 不说“GPT‑5.6 全球综合能力第一”。允许使用“第一梯队”“在复杂代码和 Agent 任务上很强”等与公开对比相匹配的表述；所有分数必须标注为 OpenAI 官方公开对比数据。
- 如需提到 ChatGPT 用户体量，用“接近十亿周活”即可，不在视频中展开数字来源。
- 不需要提套餐、地区、权限、下载、安装、登录或外网使用入口。
- 可以展示和解释新版桌面端，但不口播“建议大家下载 ChatGPT 桌面端 App”，也不做任何下载、安装或入口引导；把价值落回“它把聊天、做事、写代码放进了同一个工作台”。
- 不点名竞品作为主论据；“聊天 / 办公 Agent / 编程环境分开”只作为本条视频的产品判断。
- Sites、模板、可视化等功能以前后截图和真实案例说话，不做“输入一句话就完美交付”的广告式演示。
- 发布前仍检查标题、封面、前 30 秒和案例画面，避免出现外网服务入口、下载或账号登录教学。
