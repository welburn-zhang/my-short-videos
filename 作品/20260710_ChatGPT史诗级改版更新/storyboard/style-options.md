# 分镜主视觉风格样张

对比画面统一使用「聊天框升级为 AI 工作台」这一核心场景，均为 `16:9` 横版，采用 `bottom-left-avatar-slot`，底部预留约 20% 字幕安全区。

## A｜暖色杂志信息图

- 文件：`style-a-editorial.png`
- 特点：奶油纸张质感、暖黄光、橙色强调、扁平信息图。
- 适合：小白科普、功能解释、清单梳理。
- 取舍：最清楚亲和，但产品的科技感相对较弱。

## B｜轻拟物 3D 工作台

- 文件：`style-b-soft-3d.png`
- 特点：圆润 3D 模型、真实光影、桌面工作台隐喻。
- 适合：功能更新、案例转场、前后效果展示。
- 取舍：视觉冲击强、容易吸引注意，但复杂信息不宜放得太多。

## C｜科技感界面拼贴

- 文件：`style-c-tech-collage.png`
- 特点：深色背景、玻璃界面、橙色连接线、产品发布感。
- 适合：重大改版、模型能力、Chat / Work / Codex 入口解释。
- 取舍：最贴合本条“史诗级改版”的主题，但整体气质更偏科技内容。

## 建议

推荐优先选择 **C** 作为整条视频的主视觉，再在周报和学习计划案例中保留暖色奶油卡片，能够兼顾更新的科技感和普通用户的理解成本。
