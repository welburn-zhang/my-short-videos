# MCP 是什么｜分镜插入说明

## 已确认视觉基线

- 风格：深黑 / 深蓝背景，蓝紫辉光，少量黄绿色点缀，Q 版奇幻 RPG 任务界面，圆润游戏化造型。
- 基线文件：`storyboard/style-approved-rpg.png`
- 人物布局：全部使用 `bottom-left-avatar-slot`，左下保留空圆形真人位。
- 字幕安全区：画面底部约 20% 保持深色、低对比，不放关键信息。
- 生成方式：Codex 内置 `imagegen`，high quality；所有画面均为独立 16:9 插入图。
