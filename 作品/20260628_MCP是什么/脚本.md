## 脚本文案（拍摄版，剪映分批录制）

你最近应该总能听到 Agent、Skill、MCP 这三个词，但放到一起，很多人就彻底懵了。它们到底各自管什么，又是怎么让 AI 从只会聊天，慢慢变成能自己干活的助手？今天就用最通俗的方式，把这三个概念和它们的关系一次讲清楚。那我们开始吧。

先来看 Agent。Agent 就像游戏里接任务的角色，你只要告诉它最后要做成什么，它会自己想下一步干嘛。比如你说，帮我写一份下个季度的活动方案，要包含目标、用户、执行节奏和预算。这就是给 Agent 发了一个主线任务。
Skill 呢，就是它背包里的技能书或者通关攻略。它会告诉 Agent，先搞清楚活动目标和受众，再参考过去的方案和数据，最后按固定结构写出来。
那角色有了，攻略也有了，为什么有时候还是感觉笨笨的呢？因为它还找不到完成任务需要的资料。它知道要参考去年的方案，但打不开你的文档；它知道要根据过去的数据调整预算，但看不到你的数据表。这时候就轮到 MCP 上场了。

MCP 没有那么复杂。你可以把 AI 想成一个刚入职的同事。以前它想看文档、读表格，需要学习怎么找。MCP 就是定了一套通用的对接方式。有了它，AI 就能用相似的方式去找资料、读信息、调用工具。但它最后能看什么、能改什么，还是由你给的权限决定。

好，这三个词现在放到一起，就很好理解了。Agent 负责接任务、想办法往下做；Skill 告诉它这件事应该按什么流程做；MCP 负责把需要的资料和工具接进来。

比如写周报，Agent 负责接下“完成周报”这个任务，Skill 规定周报要写项目进度、遇到的问题和下周计划，MCP 帮它按统一方式去读取你授权的工作记录，包括各种文档和数据库。
开会前，它可以根据相关文档整理背景、未解决的问题和这次要确认的事情。
学一个新工具时，它可以读你授权的教程和笔记，找到你卡住的地方，再按学习 Skill 给你安排下一步。
做资料研究时，它可以先按 Skill 判断要找什么，再连接 MCP 搜索文档和整理信息。

有一点要注意，使用mcp的前提是，你用的 agent已经接入了相应能力，并且你给了它合适的权限。
最后只要记住一句话：Agent 接任务，Skill 给方法，MCP 接工具。好了，记得点赞收藏+关注，后面我会分享更多适合小白观看的AI内容，我们下期再见，拜拜。
