## 脚本文案（拍摄版，剪映分批录制）

欢迎来到 AI 新手村启蒙篇。今天这一关，我们来搞懂什么是 Token。
上一期讲解了什么是prompt提示词，以及如何把需求说清楚。其实大模型并不是直接处理我们人类所看到的文字，它会先用一个文字切分工具，把句子拆成大小不一样的块。可以把大模型想成主厨，把 文字切分工具想成后厨里负责切菜的小弟。每切出来一块，再交给主厨处理，这一块就是一个 Token。

这个切菜小弟不是“一字切一刀”。有时一个字是一块，有时一个词是一块，标点符号或者英文单词的一部分也可能单独成块。不同模型使用的 切分工具可能不一样，所以同一句话，切出来的结果也可能不同。

我来演示一下，我发一句中文“你好，我是张半蛋”，你看，文字被切成了不同颜色的小块。我再发一句英文“hello,my name is zhangbandan”，单词和标点符号也会被切分成不同颜色的小块，这里的颜色只是为了标出每一刀切在哪里，AI 并不会真的看见这些颜色。所以 Token 不等于字数，也不等于单词数。对模型来说，一段话有多长，不是看字数，而是看一共切出了多少个 Token。

这也能解释为什么模型介绍里总会写“支持多少 Token 上下文”，其实上下文窗口就像厨师的一张工作台。当前这次对话里，历史对话、本次输入内容，还有模型接下来要生成的回答，通常都会占用工作台空间，而这张工作台能摆下的 Token 是有上限的。如果超过了，会截断或压缩前面的内容，所以很多模型说的“支持 100 万上下文”，说的不是 100 万个汉字，而是最多能容纳100万个 Token。

而且Token 不只和输入有关，也和 AI 怎么生成回答有关。你会发现，AI 的回答通常不是整段一下出现，而是像打字一样一点点出来。因为大多数大语言模型生成内容时，会根据前面的信息，一个 Token 接一个 Token 地预测后面的内容，再把它们连成完整的回答。所以 Token 不只是文字被切出来的小块，也是模型生成回答时一步一步使用的单位。
