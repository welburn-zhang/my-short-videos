## 脚本文案（拍摄版，剪映分批录制）

AI 的回答，通常都是一点一点往外蹦。为什么不是整段一下出来呢？这个现象，就和 Token 直接相关。
欢迎来到 AI 新手村启蒙篇。今天这一关，我们来搞懂什么是 Token。
我们把一句话发给 AI 以后，它不是按整句话直接处理，而是会先用一个文字切分工具，把句子拆成大小不一样的块。你可以把大模型想成主厨，把文字切分工具想成后厨里负责切菜的小弟。它切出来一块，就交给主厨处理，这一块就是一个 Token。

这个切菜小弟不是“一字切一刀”。有时一个字是一块，有时一个词是一块，标点符号或者英文单词的一部分也可能单独成块。不同模型使用的 切分工具可能不一样，所以同一句话，切出来的结果也可能不同。

我来演示一下，我发一句中文“你好，我是张半蛋”，你看，文字被切成了不同颜色的小块。我再发一句英文“hello,my name is zhangbandan”，看，单词和标点符号也会被切分成不同颜色的小块，这里的颜色只是为了标出每一刀切在哪里，AI 并不会真的看见这些颜色。所以 Token 不等于字数，也不等于单词数。对模型来说，一段话有多长，不是看字数，而是看一共切出了多少个 Token。

这也能解释为什么模型介绍里总会写“支持多少 Token 上下文”，其实上下文窗口就像厨师的一张工作台。当前这次对话里，历史对话、本次输入内容，还有模型接下来要生成的回答，通常都会占用工作台空间，而这张工作台能摆下的 Token 是有上限的。如果超过了，会截断或压缩前面的内容，所以很多模型说的“支持 100 万上下文”，说的不是 100 万个汉字，而是最多能容纳100万个 Token。

回到开头那个问题，AI 的回答为什么会一点一点往外蹦？因为大多数大语言模型生成内容时，会根据前面的信息，一个 Token 接一个 Token 地预测后面的内容，再把它们连成完整的回答。所以 Token 不只是文字被切出来的小块，也是模型生成回答时一步一步使用的单位。
