# Scene 06｜上下文窗口容量动画

根据 `scene-06-first-frame.png` 和 `scene-06-last-frame.png`，生成一段 12 秒、16:9、固定机位的黑色舞台概念动画。

圆形厨师工作台代表上下文窗口。保持画面中的工作台形状、蓝紫色边框、左下头像圆框、字体和 Token 块风格一致。所有普通口播字幕由剪映后期添加，视频内不生成其他文字。

## 00:00—00:01

保持首帧构图。圆形工作台为空，三组 Token 块停在工作台外侧，黄色箭头轻微亮起。

## 00:01—00:04

“历史对话”Token 块从左上方依次滑入圆形工作台，整齐占据桌面左侧。每一块进入时有轻微落位反馈，不弹跳、不旋转。

## 00:04—00:06

“本次输入内容”Token 块从正上方依次进入，占据桌面中间区域。原有历史对话向左轻微让位，但仍完整保留。

## 00:06—00:08

“模型回答”Token 块从右上方依次进入，占据桌面右侧。桌面逐渐被填满，蓝色边框轻微亮起，表示容量即将达到上限。

## 00:08—00:09.5

工作台已经装满。所有 Token 块短暂停住，右侧出现新的橙色 Token 块并标记为“新内容”。

## 00:09.5—00:11

“新内容”持续从右侧进入工作台。新块每进入一组，桌面现有内容就整体向左移动一格；最早进入的“历史对话”逐块越过桌面左边缘，淡出并离开画面。这个挤出过程必须连续、清楚，不能瞬间消失。

## 00:11—00:12

形成尾帧构图。新内容已经进入工作台，最早的历史对话被挤出。左侧出现橙色提示“截断 / 压缩前文”，保持到视频结束。
